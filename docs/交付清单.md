# 「皮影演奥斯卡」· 13 部动画复刻工程

仓库即工程：引擎在 `engine/`，配音在 `voice/`，拆解/渲染工具在 `pipeline/`。
引擎底座：huashu-art-motion 技能 `scripts/engine/`（已复制到 `engine/`）
风格卡：`references/风格配方/34_shadowpuppet.md`（皮影）

## 一、复刻原则

按技能的方法论：**复刻是学机制，不是逐像素**。

- **皮影.mp4**：先用 `breakdown.py` 拆原片（115.47s / 1280×720 / 30fps / HEVC），得到 75 个转场点、节拍网格 step=6 帧（≈150 BPM）、78 段参考帧；再看接触表还原情节线，最后提取**视觉与运动签名**重画，压到 30s / 6 幕。
- **12 部短片**：原片是各自不同的 3D/手绘风格，无法逐像素复刻。统一套用皮影视觉语言——这是取舍：**统一成一个"皮影演奥斯卡"系列才有辨识度，也才能批量产出**。若要还原各自原作画风，需逐部换渲染器。

## 二、皮影视觉签名（全部 13 部共用）

| 要素 | 实现 |
|---|---|
| 幕布 | 暖黄纸底 + 中央光晕（灯箱抖动）+ 四周暗角 + 纸纹颗粒 |
| 皮件 | 黑褐剪影 + 镂空刻纹（`K.dots`/`K.clouds`/`K.lines`/`K.lattice`） |
| 配色 | 朱红 `#c0352a` / 靛蓝 `#2c5a8a` / 草绿 `#2f7d4c` / 赭黄 `#d99a2e` / 纸白 `#f6ecd6` |
| 关节 | 皮件是刚体，只绕铆钉转（无形变） |
| 运动 | `step(t, 10)` 按 10fps 一顿一顿（定格感） |
| 操杆 | 从皮件往下、往外走，blur + multiply（道具感） |
| 画框 | 深色木框 + 暗角（`frame(c)`） |

## 四、目录结构

```

│  ├─ transitions.js           转场库

│  ├─ scenes/piying_remake.js  皮影.mp4 复刻（6 幕）
│  ├─ scenes/oscar_a.js        鹬 / 回忆积木小屋

│  ├─ eras_piying.js … eras_bear.js   13 张段落表（{id, dur, transition}）
│  └─ lib/                     通用绘制库 + 48 个字体子集
├─ pipeline/                   拆解与渲染工具（render.py / breakdown_local.py / compare.py）
├─ voice/                      配音与发布：build_voice_remake.py / ambience.py / prepare_channels_remake.py
```

成片、字幕、原片素材、审片截图**不在仓库内**（体积 + 版权），需本地自行渲染。

## 五、渲染命令

```bash
cd engine
python render.py --film <key> --fps 60 --out ./out/<片名>.mp4
python render.py --film <key> --stills 2.0,7.0 --out ./stills/<key>   # 抽静帧
```

`--film <key>` 对应 `eras_<key>.js`。
